# De Lucru — Exerciții POO C++ (Fișier Personal)

**Materie:** Programare Orientată pe Obiecte (POO) · **An:** Anul 2

## Ce face

Fișier personal acumulat pe tot parcursul materiei POO, conținând mai multe exerciții/clase comentate. Funcționează ca un caiet de note executabile în C++.

## Concepte / tehnologii folosite

- Clase cu `const` member (`serialNumber`)
- Atribut static (`tipImprimanta`), getter/setter statici
- Metodă statică de calcul (`getTotalPaginiPerProducator`)
- Compoziție: `Imprimanta` are un `Cartus`
- Moștenire: `ConglomeratImprimate : public Imprimanta`
- `operator<<` (friend), `operator=`, constructor de copiere
- Clase comentate (exerciții anterioare): `TrotinetaElectrica`, `Zbor`, `Tramvai/TramvaiHibrid`, `numarMare`
