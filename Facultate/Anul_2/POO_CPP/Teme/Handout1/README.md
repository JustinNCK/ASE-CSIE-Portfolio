# Handout 1 — Pointeri de Bază

**Materie:** Programare Orientată pe Obiecte (POO) · **An:** Anul 2

## Ce face

Exerciții cu pointeri de bază în C++: inițializare cu NULL, accesul la adrese, aritmetică de pointeri, lucrul cu `void**` și cast-uri de tip.

## Concepte / tehnologii folosite

- Pointeri la tipuri primitive (`int*`, `float*`, `double*`, `long*`)
- Aritmetică de pointeri (`pointer + 1`, `pointer - 2`)
- Pointer la pointer (`int**`, `void**`)
- Cast-uri de tip pentru `void**`
- Teste unitare Microsoft CppUnitTestFramework
