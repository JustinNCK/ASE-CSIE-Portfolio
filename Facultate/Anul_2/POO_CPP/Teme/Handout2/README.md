# Handout 2 — Pointeri Avansați, Șiruri, Matrice

**Materie:** Programare Orientată pe Obiecte (POO) · **An:** Anul 2

## Ce face

Exerciții avansate cu pointeri, șiruri de caractere alocate dinamic și matrice. Include funcții pentru: maximul unui vector, copiere șir, verificare egalitate, matrice unitate, minim pe linii, arhivare șir (RLE).

## Concepte / tehnologii folosite

- Alocare/dezalocare dinamică (`new[]`, `delete[]`)
- `char*` și operații pe șiruri (`strcpy_s`, `strcmp`)
- Matrice dinamice (`int**`)
- Compresie RLE (run-length encoding) — ex: `AAABBC` → `3A2BC`
- Teste unitare Microsoft CppUnitTestFramework
