# Pregătire Examen Java — Flotă de Vehicule

**Materie:** Java · **An:** Anul 2

## Ce face

Proiect de pregătire pentru examenul de Java: modelează o flotă de vehicule cu ierarhie de clase, interfețe și excepții custom. Demonstrează conceptele tipice de examen: clasă abstractă, interfață, excepție proprie, colecție.

## Concepte / tehnologii folosite

- Clasă abstractă `Vehicul`
- Moștenire: `Camion`, `Autoutilitara`
- Interfață `Evaluabil`
- Excepție custom `CapacitateDepasitaException`
- Colecție `Flota`

## Fișiere principale

- `src/Vehicul.java` — clasă abstractă de bază
- `src/Camion.java`, `src/Autoutilitara.java` — clase derivate
- `src/Evaluabil.java` — interfață
- `src/CapacitateDepasitaException.java` — excepție custom
- `src/Flota.java` — gestiune colecție vehicule
- `src/Main.java` — punct de intrare
