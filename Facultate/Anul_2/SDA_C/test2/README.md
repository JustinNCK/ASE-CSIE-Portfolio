# test2 — Listă Dublu Înlănțuită cu Comenzi

**Materie:** Structuri de Date și Algoritmi (SDA) · **An:** Anul 2

## Ce face

Implementare completă în C a unei liste dublu înlănțuite pentru gestionarea comenzilor. Suportă inserare, afișare bidirecțională, numărare comenzi după data livrării și ștergere selectivă.

## Concepte / tehnologii folosite

- Listă dublu înlănțuită (`struct Nod` cu `next` + `prev`)
- Alocare dinamică (`malloc`, `free`)
- Citire din fișier CSV cu `strtok`
- Operații: inserare, afișare stânga-dreapta și dreapta-stânga, numărare, ștergere

## Fișiere principale

- `test2.cpp` — implementare completă a listei dublu înlănțuite
- `Comenzii.txt` — date de intrare (gol în prezent)
