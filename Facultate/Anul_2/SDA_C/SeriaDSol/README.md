# SDA — Laboratoare C (Seria D)

**Materie:** Structuri de Date și Algoritmi (SDA) · **An:** Anul 2

## Ce face

Set alternativ de laboratoare SDA pentru seria D, cu aceeași progresie tematică: limbaj C de bază, preprocesare, liste înlănțuite și tabele hash cu sondare liniară.

## Concepte / tehnologii folosite

- Bazele limbajului C și preprocesare
- Liste simplu și dublu înlănțuite
- Tabela Hash cu sondare liniară (linear probing)

## Fișiere principale

- `SeriaDProj/01_Limbaj.c` — bazele limbajului C
- `SeriaDProj/02_Preproc.c` — preprocesare, directive
- `SeriaDProj/03_ListeSImple.c` — liste simplu înlănțuite
- `SeriaDProj/04_ListeDuble.c` — liste dublu înlănțuite
- `SeriaDProj/05_HashTable_LinProb.c` — Hash Table cu sondare liniară
- `SeriaDProj/Studenti.txt` — date de test (fictive)
