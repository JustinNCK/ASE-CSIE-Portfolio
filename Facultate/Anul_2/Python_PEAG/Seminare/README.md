# PEAG — Seminare Python

**Materie:** Programare Evolutivă și Algoritmi Genetici (PEAG) · **An:** Anul 2

## Ce face

Colecție de 8 seminare care acoperă progresiv algoritmii de optimizare: de la Hill Climbing la Algoritmi Genetici compleți cu selecție, mutație și recombinări avansate. Problemele rezolvate: N-Queens, Rucsac 0/1, Rucsac continuu, TSP.

## Concepte / tehnologii folosite

- NumPy, Matplotlib
- Hill Climbing (1 var, 2 var, binar, întreg)
- Algoritmi Genetici: populație, fitness, selecție, mutație, recombinări
- Operatori de mutație: binar, permutări
- Recombinări: unipunct, multipunct, OCX, PMX, CX
- Strategii de selecție: 6 distribuții + 8 strategii

## Structură

- `sem_1/` — numpy, N-Queens primă implementare
- `sem_2/` — Hill Climbing pe diverse reprezentări
- `sem_3/` — schelet Algoritmi Genetici
- `sem_4/` — GA + `Mutatii.py`
- `sem_5/` — probleme speciale
- `sem_6/` — GA + Mutatii + Recombinari
- `sem_7/` — Problema 5
- `sem_8/` — GA complet + Selectii avansate (**nota: `caini_si_pisici.py` conține un bug de sintaxă C# în Python**)
