# Bază de Date Spital — Proiect BD

**Materie:** Baze de Date (Oracle SQL) · **An:** Anul 2

## Ce face

Schemă relațională completă pentru gestionarea unui spital. Conține 7 tabele cu relații de tip cheie primară/cheie externă, constrângeri `CHECK`, valori implicite `DEFAULT SYSDATE` și ștergere în cascadă (`CASCADE`).

## Concepte / tehnologii folosite

- Oracle SQL DDL: `CREATE TABLE`, `PRIMARY KEY`, `FOREIGN KEY`
- Constrângeri: `CHECK`, `NOT NULL`, `UNIQUE`
- Relații: `CASCADE` la ștergere
- `DEFAULT SYSDATE` pentru înregistrare automată dată
- 7 tabele interconectate
