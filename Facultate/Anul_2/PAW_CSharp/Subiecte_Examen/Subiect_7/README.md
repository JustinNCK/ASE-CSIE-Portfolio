# Subiect 7 — Evenimente Culturale

**Materie:** Programare Avansată Windows (PAW) · **An:** Anul 2

## Ce face

Aplicație WinForms pentru gestionarea evenimentelor culturale (concerte, filme). Folosește o clasă abstractă cu validare în setters.

## Concepte / tehnologii folosite

- Clasă abstractă `Eveniment` cu validare în proprietăți (setters)
- Moștenire: `Concert`, `Film`
- Windows Forms cu formular de adăugare

## Fișiere principale

- `Eveniment.cs` — clasă abstractă cu validare în setters
- `Concert.cs`, `Film.cs` — clase derivate
- `AdaugaEveniment.cs` — formular adăugare
- `Form1.cs` — fereastra principală
