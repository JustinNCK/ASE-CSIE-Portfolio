# Subiect 8 — Service Auto

**Materie:** Programare Avansată Windows (PAW) · **An:** Anul 2

## Ce face

Aplicație WinForms pentru gestionarea unui service auto: mașini și reparații asociate.

## Concepte / tehnologii folosite

- Clase: `Masina`, `Reparatie`, `Service`
- Windows Forms cu formular de adăugare

## Fișiere principale

- `Masina.cs`, `Reparatie.cs` — modele
- `Service.cs` — logică service
- `Adaugare.cs` — formular adăugare
- `Form1.cs` — fereastra principală
