# Restaurant — Aplicație Gestiune Meniu

**Materie:** Programare Avansată Windows (PAW) · **An:** Anul 2

## Ce face

Aplicație Windows Forms pentru gestionarea meniului unui restaurant. Fiecare produs din meniu are ingrediente asociate, iar prețul final se calculează automat din costul ingredientelor plus un adaos.

## Concepte / tehnologii folosite

- Clase: `Ingredient`, `Produs`
- Calcul preț derivat din lista de ingrediente + procent adaos
- Windows Forms (WinForms)

## Fișiere principale

- `Ingredient.cs` — ingredient cu cost unitar
- `Produs.cs` — produs cu lista de ingrediente, calcul preț
- `Form1.cs` — interfața principală
- `Program.cs` — punct de intrare
