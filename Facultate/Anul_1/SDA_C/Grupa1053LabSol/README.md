# SDA — Laboratoare C (Seria 1053)

**Materie:** Structuri de Date și Algoritmi (SDA) · **An:** Anul 1

## Ce face

Colecție de laboratoare săptămânale de Structuri de Date în C, acoperind progresiv tipurile de date de bază, pointeri, liste înlănțuite și tabele hash. Fiecare seminar este un proiect Visual Studio separat.

## Concepte / tehnologii folosite

- Tipuri de date și operatori C
- Argumente linie de comandă (`argc`, `argv`)
- Structuri (`struct`) și câmpuri
- Liste simplu înlănțuite, dublu înlănțuite, circulare
- Tabele Hash cu înlănțuire (chaining)
- Alocare dinamică (`malloc`, `free`)

## Structură

- `sem1/` – `sem7/` — laboratoare săptămânale progresive
- `08_ABC/` — exerciții linie de comandă (inversare, copiere fișier)
- `testez/Clienti.txt` — date de test (fictive, 10 clienți)
