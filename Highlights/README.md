# 🌟 Highlights

## 1. [Proiect Gestiune Vânzări (C#)](../Facultate/Anul_2/PAW_CSharp/Proiect_Gestiune_Vanzari)
Cel mai complex proiect C#: delegați și evenimente (`ModificarePretDelegate`, `PretModificat`), interfețe multiple (`ICloneable`, `IComparable`, `IEnumerable`, `IReducere`), control WinForms custom, serializare XML.

## 2. [Baza de Date a unui Spital (SQL)](../Facultate/Anul_2/BD_SQL/Proiect_Spital)
Schemă relațională completă cu 7 tabele, constrângeri `CASCADE`, `CHECK`, chei primare/externe corect implementate.

## 3. [Sistem Gestiune Spital (Java + SQLite + JSON)](../Facultate/Anul_2/Java/Subiect2_Spital)
Integrare OOP + bază de date: clase `Pacienti`/`Sectii`, persistență SQLite, schimb de date prin JSON.

## 4. [Proiect BTI (Assembly x86)](../Facultate/Anul_1/BTI_Assembly/Proiect_BTI)
Program complet în MASM/TASM pentru operații aritmetice în cod complement față de 2, proceduri separate, gestionare stivă, întreruperi DOS.
