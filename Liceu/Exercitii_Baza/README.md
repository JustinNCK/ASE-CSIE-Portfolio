# Exerciții de Bază — Liceu C/C++

Exerciții clasice din clasele 9-10, acoperind construcțiile de bază ale limbajului C++.

## Conținut

| Folder | Subiect |
|---|---|
| `if_else/` | Par/impar, pozitiv/negativ, maxim, numere pare |
| `lucarm/` | Numere prime, inversare vector, sumă |
| `tema/` | Exerciții cu cifre, matrice, structuri de control |
| `tema_vacanta/` | Probleme pbinfo (#633, #546, #488) |
| `teza/` | Factorizare, cmmdc, cmmmc |
| `subprograme/` | Funcții: sumă, medie aritmetică |
| `sortaarii/` | Algoritmi de sortare (schelet) |
| `siruri_de_caractere/` | `char[]`, `strchr`, `cin.getline`, vocale |
| `structuri/` | `struct elev` (nume, vârstă, clasă, medie) |
