# Structuri de Date Timpurii — Liceu/An 1 C++

Primele implementări de structuri de date, realizate parțial în liceu (avansat) și parțial în primul an de facultate.

## Conținut

| Folder | Subiect |
|---|---|
| `stiva/` | Stivă cu `struct Film` (push/pop/golire/afișare din fișier) |
| `SDA/` | Liste circulare cu `struct produs` (denumire, preț) |
| `recapitulare/` | `malloc`, bubble sort cu pointeri, eliminare duplicate |
| `sa_lucramj/` | Procesare matrice pixeli RGB, submatrice maxime pe canale |
| `hash_map/` | Hash map cu firme și date service auto |
| `liste_dublu_inlantuite/` | Liste dublu înlănțuite cu date apeluri |
