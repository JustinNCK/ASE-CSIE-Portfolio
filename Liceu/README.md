# Liceu — Arhivă C/C++

Colecție de proiecte și exerciții din perioada liceului, organizate cronologic. Păstrate intenționat pentru a ilustra progresia de la exerciții de bază până la nivel de concurs.

## Structură

| Folder | Conținut |
|---|---|
| [Exercitii_Baza/](./Exercitii_Baza) | Exerciții clasice: if/else, vectori, șiruri de caractere, structuri |
| [Structuri_Date_Timpurii/](./Structuri_Date_Timpurii) | Stivă, liste, hash map — primele structuri de date |
| [Jocuri/](./Jocuri) | Jocuri consolă: Tic-Tac-Toe |
| [Concurs/](./Concurs) | Soluții Acadnet 2017, Olimpiadă Națională 2023 |
| [Pregatire_BAC/](./Pregatire_BAC) | Soluții comentate BAC 2023 informatică |
| [Pregatire_Admitere/](./Pregatire_Admitere) | Variante admitere Unibuc 2019 |
| [Diverse/](./Diverse) | Exerciții diverse, scratch, experimente |
