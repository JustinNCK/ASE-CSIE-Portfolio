# Jocuri Consolă — Liceu C++

## X_si_O — Joc Tic-Tac-Toe

Implementare completă a jocului Tic-Tac-Toe pe consolă pentru 2 jucători.

**Funcționalități:**
- Tablă vizuală afișată după fiecare mutare
- Validare mutări invalide
- Verificare automată câștigător (linii, coloane, diagonale)
- Detectare remiză

**Fișiere:** `X_si_O/main.cpp`
