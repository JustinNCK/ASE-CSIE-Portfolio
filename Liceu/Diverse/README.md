# Diverse — Liceu C/C++

Fișiere și proiecte diverse: experimente, exerciții incomplete, scratch-uri și foldere de test. Păstrate pentru istoric.

## Conținut

- `incerc/` — experiment cu fișiere relative/absolute și liste studenți generate
- `lucram/` — exercițiu cu citire din fișier și prelucrare vector
- `tema1/` — exercițiu avansat (conținut parțial)
- `POO/prob.cpp` — exercițiu POO izolat
- `grafuri/`, `grafuri2/` — exerciții cu grafuri
- `divide_et_imper/` — exerciții divide et impera
- `pointeri/` — exerciții pointeri
- `cozi/` — exerciții cu cozi
- `lucru/`, `chesti/` — scratch/test
- `testez/`, `test/`, `teste/`, `problema/`, `probleme/` — fișiere test diverse
